IMAGE SLOTS
===========

Drop image files here, named after their slot ID.

  HOME-HERO.jpg   ->   <Figure slot="HOME-HERO" />

Accepted extensions: .jpg .jpeg .png .webp .avif
The first match wins, so keep only one file per slot.

No code change is needed. Until a file exists the slot renders generated
terracotta artwork, so the site always looks finished.

Prompts, target sizes and generation order:  docs/image-prompts.md
Where each slot sits in the page:            docs/design-blueprint.md
